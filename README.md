🪨📄✂️ Stone Paper Scissors – Python Game

A simple command-line Stone–Paper–Scissors game written in Python where a human player competes against the computer. The first player to score 5 points wins the game.

🚀 Features

Interactive command-line gameplay

Randomized computer moves

Input validation for user choices

Score tracking for both player and computer

Automatic game termination when a player reaches 5 points

🧠 Game Rules

Rock (1) beats Scissors (3)

Paper (2) beats Rock (1)

Scissors (3) beats Paper (2)

Same choice results in a draw

First to reach 5 points wins the game

🛠️ Technologies Used

Python 3

Built-in random module

📦 Installation & Setup

Make sure Python 3 is installed on your system

python --version


Clone this repository

git clone https://github.com/your-username/stone-paper-scissors.git


Navigate to the project directory

cd stone-paper-scissors


Run the game

python main.py

🎮 How to Play

When prompted, enter:

1 → Rock

2 → Paper

3 → Scissors

Example input:

press 1- for rock, press 2 for paper and press 3 for scissors:-


The game will display the result of each round along with the current score.

🏆 Winning Condition

You win if your score reaches 5

Computer wins if its score reaches 5
